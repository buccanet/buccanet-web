# Code of conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies in the repository, its issues, its pull requests and every other project space.

## Reporting

Report unacceptable behavior to the maintainers at hello@buccanet.com. As the Covenant requires, the maintainers respect the privacy and security of the person who reports.

## Enforcement

The maintainers apply the enforcement guidelines of the Contributor Covenant 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
